# 🏛️ 중학교 사회 직접민주주의 메타버스 총회 웹앱

중학교 사회 수업(직접민주주의)을 위한 28명 동시 접속 2D 탑뷰 메타버스 웹앱입니다.  
학생 태블릿(iPad, Galaxy Tab 등) 터치 환경에 완벽하게 최적화되어 있습니다.

## 🚀 주요 기능
- **태블릿 터치 조작**: 가상 조이스틱(Virtual Joystick) 및 화면 터치(Tap) 목적지 이동 하이브리드 지원
- **소회의실 분리 토론**: 중앙 광장(아고라) 및 외곽 7개 카페 (각 카페당 최대 정원 4명 엄격 제한, 초과 시 튕겨남)
- **교사 관리자 콘솔 (`?admin=true`)**:
  - 안건 퀵 버튼 3종 (원터치 학생 화면 배너 5초 강조 송출 후 상단 고정)
    1. 촉법소년 제도 폐지 찬반
    2. 교내 스마트폰 반입/사용 전면 금지 의무화 찬반
    3. 노키즈존(노틴존) 법적 금지 찬반
  - 광장 소환 버튼 (소회의실 인원 전원 중앙 광장으로 강제 워프)
  - 투표 활성화 및 실시간 찬/반/미투표 집계 그래프
  - 발언 신청 대기열(✋) 순차 관리
- **실시간 사운드 동기화**:
  - 배경음악 (`assets/bgm swiss.mp3` - 볼륨 30% 루프)
  - 찬성 (`assets/Success bell.mp3`)
  - 반대 (`assets/Error beep.mp3`)
  - 발언/안건 알림 (`assets/Notification pop.mp3`)

## 🛠️ 로컬 실행 방법
```bash
npm install
npm start
```
- 학생 접속: `http://localhost:3000` (또는 교실 Wi-Fi 로컬 IP)
- 교사 접속: `http://localhost:3000/?admin=true`
